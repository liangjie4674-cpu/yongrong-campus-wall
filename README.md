# 永荣校园墙

一个手机优先的校园留言墙：学生可以**实名或匿名发帖（可带图片）**，所有帖子、留言**和图片先经管理员审核**才会公开，每条帖子带**浏览量、点赞和留言**。

## 功能

- 📱 手机优先界面（底部导航 + 中央发布按钮、底部抽屉式发布/详情、深色模式、PWA 可添加到主屏幕）
- 👤 **账号体系**：注册填账号 + 密码 + 昵称即可（无邮箱/短信验证，注册完直接可用）；**未登录不能发帖和留言**；登录后可随时改昵称
- 🕶️ 发帖可勾选匿名，显示为“匿名同学”；不勾选则显示账号昵称（官方保留昵称不可注册）
- 🖼️ 可带一张图片发帖（前端自动压缩）；**图片随帖子一起审核**：未通过前图片文件本身也无法被访问，管理员在后台能看到图再决定，通过后才公开
- 🏷️ 分类：表白 / 吐槽 / 求助 / 失物招领 / 日常 / 树洞；关键词搜索；最新/最热排序；下拉刷新 + 无限滚动
- 🔥 首页热门榜（此刻最受关注的 5 条）；管理员可置顶帖子
- 👁️ 浏览量（打开详情计数，同一 IP 半小时内不重复刷）、❤️ 点赞（防重复）、💬 留言（同样先审后发）
- 📮 “我的投稿”：在本机查看自己帖子的审核状态（审核中/已上墙/未通过）
- 🛡️ 管理后台 `/admin`：审核帖子与留言（可看图）、全部通过、置顶/取消置顶、发布/撤下公告（墙面顶部展示）、已上墙搜索与分页、近 7 日发帖统计图、数据总览；敏感词命中的内容会标黄提醒
- 🚦 按真实连接 IP 限流防刷（防伪造转发头绕过）；浏览/点赞去重；前端全部 textContent 渲染防 XSS；安全响应头 + CSP
- 🔤 自带思源宋体/黑体（public/fonts，浏览器按需加载子集，离线可用）

## 快速开始

```bash
npm install        # 只装一个依赖：pg（连数据库用）
node server.js
# 打开 http://localhost:3000
# 管理后台 http://localhost:3000/admin （默认密码 yongrong-admin）
```

只需要 Node.js ≥ 18。不配数据库也能跑，数据落本地 `data/db.json`（适合本机开发）。

## 校徽 / 图标

应用图标已换成重庆市荣昌区永荣中学校徽：

- `public/icon-source.png` —— 原始校徽图（536×536，保留着以便重新生成）
- `public/icon-512.png` / `public/icon-192.png` —— 由原图缩放的 PWA 图标
- 顶栏左上角 logo、浏览器标签页图标、添加到主屏幕的图标都引用这两个文件

要换新校徽：把新图覆盖 `icon-source.png`，再执行

```bash
cd public
sips -z 512 512 icon-source.png --out icon-512.png
sips -z 192 192 icon-source.png --out icon-192.png
```

并记得把 `sw.js` 里的 `CACHE_NAME` 版本号 +1，让老用户拿到新图标。

## 上线部署

**上线一定要配数据库**，否则容器一重建，帖子和账号全没：

```bash
npm install
DATABASE_URL=postgres://用户名:密码@主机:5432/库名 \
ADMIN_PASSWORD=换成你的强密码 \
PORT=3000 node server.js
```

- 数据库只要求是 PostgreSQL 12+，启动时自动建表（`wall_doc` 存整份数据、`wall_file` 存图片），**不用手动导入 SQL**。
- 数据库要求 SSL 时加 `PGSSL=1`。
- 没配 `DATABASE_URL` 会自动退回本地文件模式，并在启动日志里报警告。

建议用 pm2 常驻（**只跑一个实例**）：

```bash
npm i -g pm2
ADMIN_PASSWORD=换成你的强密码 DATABASE_URL=… pm2 start server.js --name yongrong-wall
pm2 save && pm2 startup
```

有域名的话，用 Nginx 反代到 127.0.0.1:3000 并配 HTTPS；**反代部署时加环境变量 `TRUST_PROXY=1`**，限流才会按真实用户 IP 计算。

Abasthan 这类「按 Git 仓库部署」的平台，配置见 [DEPLOY-ABASTHAN.md](DEPLOY-ABASTHAN.md)。

## 数据

两种后端，由 `DATABASE_URL` 决定，业务代码完全一样：

| 模式 | 触发条件 | 存哪 | 重新部署会丢吗 |
| --- | --- | --- | --- |
| PostgreSQL | 配了 `DATABASE_URL` | 库里 `wall_doc`（帖子/账号/留言/设置）+ `wall_file`（图片） | 不会 |
| 本地文件 | 没配 | `data/db.json` + `data/uploads/` | 会（容器重建即丢） |

- 用户密码用 scrypt 加盐哈希存储（`salt` + `hash`），不存明文；登录态是 30 天有效的 token。
- 数据文件损坏时服务会先把坏文件改名为 `db.json.bad-<时间戳>` 再重建，不会静默丢数据。
- 首次启动（空库）会自动生成 3 条管理员欢迎帖子。
- 管理员密码只通过环境变量 `ADMIN_PASSWORD` 设置，不要写进代码；未设置时启动日志会告警。
- 备份：`pg_dump` 导出整个库即可，图片也在库里，一个文件全带走。

## 账号与权限

| 能力 | 未登录 | 已登录 |
| --- | --- | --- |
| 浏览、搜索、点赞 | ✅ | ✅ |
| 发帖、留言 | ❌ 提示先注册 | ✅ 先审后发 |
| 我的投稿（审核状态） | ❌ | ✅ 只看自己的 |
| 修改昵称 | ❌ | ✅ 账号抽屉里改 |

- 注册限流：同一 IP 10 分钟内最多 8 次；登录 15 次。
- 账号规则：3-20 位字母/数字/下划线/中文；密码 6-64 位。
- 管理员在后台能同时看到“昵称 + @账号”，匿名帖也能追溯到账号（前台仍显示匿名同学）。
- 昵称修改后，**旧帖子保留发布时的昵称**，新帖子用新昵称。

```

lib/store.js       存储层（PostgreSQL / 本地文件双后端，按 DATABASE_URL 自动选择）
public/
  index.html       墙面主页
  styles.css       全部样式（含深色模式）
  fonts.css        自托管字体定义（思源宋体/黑体子集）
  fonts/           字体文件（woff2 子集，按需加载）
  app.js           主页逻辑
  admin.html       管理后台
  admin.js         后台逻辑
  manifest.json    PWA 清单
  sw.js            Service Worker（静态缓存，接口不缓存）
  icon-192.png / icon-512.png   应用图标（校徽）
  icon-source.png  校徽原图（可重新缩放生成上面两个）
data/db.json       数据文件（运行时生成）
data/uploads/      通过/待审帖子的图片（运行时生成）
DESIGN.md          产品与 UI 设计规格
```
